# Hands-On AI for HR

Workbook for the session **From Asking to Assigning: Hands-On AI for HR**.

## [Open the workbook](https://docs.google.com/document/d/1YrZLC2i6_oDy0BMQCj1Wq4s-ewbogY2E/edit?usp=sharing&rtpof=true&sd=true)

- Open the workbook on the same computer as your agent harness (Claude Cowork, Microsoft Copilot Cowork, or ChatGPT Work), so that you can copy and paste each prompt.
- You cannot type in the workbook. Write your answers on paper or in a notes app.
- To keep a copy, use File → Download in the workbook.

Session by Don Shin, [CrossComm](https://crosscomm.com).
